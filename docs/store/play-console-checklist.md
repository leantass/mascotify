# Play Console checklist - Mascotify beta/internal testing

## Preparacion de app

- [ ] Crear app en Google Play Console.
- [ ] Confirmar package name `com.mascotify.app`.
- [ ] Configurar App signing by Google Play.
- [ ] Definir upload key y guardar keystore fuera del repo.

## Ficha de tienda

- [ ] Nombre: Mascotify.
- [ ] Descripcion corta.
- [ ] Descripcion completa.
- [ ] Icono de alta resolucion.
- [ ] Feature graphic si aplica.
- [ ] Screenshots telefono.
- [ ] Screenshots tablet si se decide soportar.

## App content

- [ ] Politica de privacidad publicada en URL publica.
- [ ] Terminos publicados en URL publica si se usan.
- [ ] Data Safety completado.
- [ ] Target audience completado.
- [ ] Ads declaration completada.
- [ ] Content rating completado.
- [ ] Declaracion de permisos revisada.

## Release interno

- [ ] Generar AAB release firmado.
- [ ] Crear Internal Testing.
- [ ] Agregar testers.
- [ ] Subir AAB.
- [ ] Completar notas de release.
- [ ] Enviar a revision interna.
- [ ] Validar instalacion desde Play Internal Testing.

## No hacer todavia

- [ ] No publicar produccion publica.
- [ ] No activar pagos reales.
- [ ] No activar AdMob produccion.
- [ ] No abrir rollout publico.
- [ ] No subir secretos, keystore ni `key.properties` al repo.
