# Notas visuales Mascotify Web

## Paleta
- `#66CCCC`: color primario tomado de `lib/theme/app_colors.dart` como `AppColors.primary`.
- `#259C9C`: variante profunda tomada de `AppColors.primaryDeep`.
- `#FF3366`: acento principal tomado de `AppColors.accent`.
- `#D61C58`: variante profunda tomada de `AppColors.accentDeep`.
- `#FFCC33`: apoyo visual tomado de `AppColors.support`.
- `#FFF2C6`: soporte suave tomado de `AppColors.supportSoft`.
- `#F7FBFC`, `#EFF8F8`, `#F3F7F8`: fondos y superficies derivados de `AppColors.background`, `backgroundSoft` y `surfaceAlt`.
- `#333333`, `#667085`, `#8A94A6`: texto y variantes derivados de `AppColors.dark`, `textSecondary` y `textMuted`.
- Referencias Flutter usadas: `lib/theme/app_colors.dart` y `lib/theme/app_theme.dart`.
